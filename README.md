## Live experiments

- [CSV Preflight](https://softpeanut.github.io/csv-preflight/) — check and normalize CSV structure locally before an import; files stay in the browser.
- [MarketPack](https://softpeanut.github.io/marketpack/) — resize product photos for four storefronts and download one organized ZIP; files stay in the browser.
- [ScopeSeal](https://softpeanut.github.io/scopeseal/) — price an out-of-scope request and draft a client approval message locally.
- [Release Proof Sprint](https://softpeanut.github.io/release-proof-sprint/) — a bounded pilot concept for reproducible release evidence; no payment is currently collected.
